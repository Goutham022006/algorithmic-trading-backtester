# Algorithmic Trading & Backtesting Engine

C++ project evolved from the original stock trading strategy simulator. The current codebase is being developed into a modular backtesting engine for historical market data, trading strategies, portfolio simulation, execution costs, performance analytics, testing, and parallel backtesting.

## Current version

### V1 — Stock Trading Strategy Simulator
- Maximum profit with up to `k` transactions using dynamic programming.
- Greedy optimization for the unlimited-transaction case.
- Transaction reconstruction with buy/sell logs.
- Terminal-based price chart visualization.
